# ShiaiFlow — live proba (subota)

Testni turnir: **3 kategorije** — 2 pojedinačne (jedna s poolovima + KO, jedna mala / direktni KO) i 1 timska (3 člana).
Oprema: 2 laptopa (svaki: prozor zapisničkog stola + prozor ekrana uz shiaijo na monitoru, F11), mobitel kao hotspot, 1–2 mobitela kao "publika", Mac mini za organizatora (Manage).

Uz svaku točku zapiši: ✓ radi / ✗ zapelo (što, kada, na kojem uređaju) / ? nejasno korisniku.

---

## 1. Prije dana turnira (organizator)
- [ ] Novi turnir kroz wizard: Create → Signup setup → Shiaijo plan → Done.
- [ ] Raspored dana ("Use a schedule?" → Yes) — prijedlog rasporeda izgleda smisleno.
- [ ] 3 kategorije iz predložaka (npr. Kyu, Dan, Team adults), jedna s dobnim ograničenjem (godište / točan datum).
- [ ] Edit tournament → status lijevo: Published → Signup open.
- [ ] Javna prijava s mobitela (2–3 natjecatelja), uključujući tim (prijava tima prema postavci).
- [ ] Bulk entry u Registration (copy iz Excela): spol, godište, pojas se upišu ispravno.
- [ ] Signup → Closed. Ždrijeb svih kategorija u Drawings (provjeri razdvajanje klubova).
- [ ] Draws na javnoj stranici: Hidden → Published (mobitel vidi ždrijeb i raspored tek nakon toga).
- [ ] Confirm draws. Shiaijo plan: 2 shiaijoa, kategorije raspoređene, Fight plan → Print (jedan shiaijo po stranici).
- [ ] PIN kreiran (Edit → Tournament basics).

## 2. Dan turnira — prijava i start
- [ ] Check-in u Registration (Present). Jedan natjecatelj "ne dođe" → Drawings → Adjust: zamjena / withdraw.
- [ ] Jedan "walk-in" dodan i ubačen u kratki pool.
- [ ] Start tournament (Manage) — tablica spremnosti točna.
- [ ] Stol 1 i stol 2: ulaz **samo PIN-om** kroz vrata **Table** (odjavljeni uređaji) → vide samo zapisnički stol i Manage (izbor shiaijoa), nema dashboarda.
- [ ] Jedan uređaj kroz vrata **Editor** s PIN-om → nema Create Tournament / Profile, dashboard odabere turnir.
- [ ] Ekrani uz shiaijo: link iz Managea, cijeli ekran, Sides ⇄ radi, ekran se ne gasi.

## 3. Bodovanje (pojedinačno)
- [ ] Hajime / Yame, sat isti na stolu i na ekranu.
- [ ] **Potvrda ippona:** klik K → "Kote (K) for …?" — sat i dalje teče; Confirm upiše bod i zaustavi sat; Cancel ne upiše ništa.
- [ ] Hansoku (jedan klik), drugi hansoku → automatski ippon protivniku.
- [ ] Undo last.
- [ ] Dva ippona završe borbu; Finish → sljedeća borba se pojavi na ekranu ("next fight").
- [ ] Hikiwake u poolu; encho u KO (prvi bod pobjeđuje); hantei (HH) ako je postavljen.
- [ ] Fusen-gachi (OO) za natjecatelja koji ne izađe.
- [ ] Borba preskočena u redu (start borbe niže) — preskočene se pomaknu ispod.

## 4. Bez interneta (najvažnije)
- [ ] Usred borbe **ugasiti Wi-Fi** na stolu 1 → oznaka "● Offline — N clicks waiting".
- [ ] Upisati 1–2 boda i Yame offline → stol prikazuje rezultat.
- [ ] **Osvježiti stranicu dok je offline** → rezultat i dalje tu.
- [ ] Pokušati Finish offline → jasna poruka, ništa se ne izgubi.
- [ ] **Upaliti Wi-Fi** → "Saving…" → "● Online"; ekran uz shiaijo i Manage pokažu iste bodove; nema duplih bodova.
- [ ] Isto na stolu 2 dok stol 1 normalno radi.

## 5. Poolovi i KO
- [ ] Poredak u poolu nakon zadnje borbe (Pool standings u Manageu, gumb na stolu, javni Draw tab).
- [ ] Namjerno izjednačenje za mjesto koje prolazi → ipponshobu F-Pn.D se pojavi na istom shiaijou.
- [ ] Pobjednici poolova uđu u KO bracket; KO borba krene čim su oba borca poznata.
- [ ] Borba za 3. mjesto (ako je uključena) prije finala.
- [ ] Manager: Correct = ponovno otvori borbu (dok na shiaijou ne teče druga) → ispravak → poredak se preračuna.

## 6. Timski meč
- [ ] Lineup korak: oba redoslijeda s papira (prijedlog iz registracije), "both handed in" → Confirm.
- [ ] Prazna pozicija (gdje je dopušteno) → fusen za drugi tim.
- [ ] Pozicije jedna za drugom, sat se resetira po poziciji; hikiwake pozicije.
- [ ] Izjednačen meč → daihyosen (odabir borca po timu, prvi bod).
- [ ] Ekran uz shiaijo: tim protiv tima, redovi po pozicijama, trenutna pozicija označena.
- [ ] Finish team match; poredak timova u poolu.

## 7. Javna strana (mobitel)
- [ ] Live tab: shiaijoi jedan uz drugi, prethodna / trenutna / sljedeće 3 borbe.
- [ ] Kategorija koja se bori otvori se sama; poredak poolova, zatim KO bracket s rezultatima.
- [ ] "Who are you" → moja sljedeća borba.
- [ ] Raspored dana na kartici Tournament.

## 8. Kraj
- [ ] Sve borbe gotove → status Finished.
- [ ] Brisanje testnog turnira (Edit → status lijevo → Delete, upis imena).
